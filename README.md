# CampusCare 🏫

### Smart College Complaint Management System

CampusCare is a web-based college complaint management system that allows students to submit and track complaints easily.

## 🚀 Live Demo

👉 [Open CampusCare Live Demo](https://campuscare-1-h6t8.onrender.com)

## ✨ Features

- Student Registration & Login
- Submit College Complaints
- Track Complaint Status
- Student Dashboard
- Admin Dashboard
- Complaint Management
- Responsive Modern UI

## 🛠️ Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
